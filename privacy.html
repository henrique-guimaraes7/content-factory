Privacy Policy — Content Factory

Last updated: 29 October 2026

Who we are

Content Factory is a private tool operated by its owner (contact: papowalker7@gmail.com) to manage the owner's own YouTube channels. It is not a public service.

What data the tool accesses

Through Google OAuth, the tool requests access only to the YouTube channels that the owner explicitly authorizes. It uses the YouTube Data API and the YouTube Analytics API to upload videos, set thumbnails, post comments on the owner's own videos, and read view and audience statistics for those videos.

How data is used and stored

OAuth tokens and video statistics are stored only on the owner's own computer. They are used solely to publish and measure the owner's videos. No data is sold, shared with third parties, or used for advertising.

YouTube API Services

Content Factory uses YouTube API Services. By using Content Factory you agree to be bound by the YouTube Terms of Service. YouTube is a Google service, and data obtained through YouTube API Services is also subject to the Google Privacy Policy.

Data accessed through YouTube API Services: the authorized channel's basic profile (ID, title, branding), its own videos and their metadata, its own playlists, comments posted by the tool on the channel's own videos, and YouTube Analytics reports (views, watch time, audience retention, subscribers) for those videos.

Information sharing

Content Factory does not share, sell or disclose any data obtained through YouTube API Services with any third party. Data is not used for advertising or profiling.

Cookies and device storage

This website does not use cookies. The tool runs only on the owner's computer and does not store, access or collect information on any other person's device or browser.

Data retention and deletion

OAuth tokens are kept only while access is authorized. Statistics about the owner's videos are kept in a local database on the owner's computer for as long as they are needed to plan future videos. If access is revoked, all data obtained through YouTube API Services is deleted from the tool within 7 days. To request deletion of stored data at any time, email papowalker7@gmail.com; requests are completed within 7 days.

Google API Services

Content Factory's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. Revoking access stops the tool immediately.
